# Introdução ao Frontend

O **Frontend** se refere à parte de um site ou aplicação web com a qual o usuário interage diretamente. Ele inclui tudo o que vemos na tela: menus, formulários, botões, animações, layout, cores e fontes. O objetivo do frontend é criar interfaces amigáveis, funcionais e esteticamente agradáveis para melhorar a experiência do usuário (UX).
